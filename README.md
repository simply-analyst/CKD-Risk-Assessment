# CKD-Risk-Assessment

## Description
Chronic Kidney Disease (CKD) is a gradual loss of kidney function over time. It is a growing global health concern affecting millions of people worldwide. Traditional methods for CKD diagnosis rely heavily on clinical expertise, laboratory tests, and medical imaging. However, these methods can be time-consuming and costly. With the advances in Machine Learning (ML) algorithms, this project aims to develop a predictive model using machine learning techniques to identify patients at risk of being diagnosed with CKD.

## Objectives
The primary objective of this project, includes:
-	Identifying key risk factors.
-	Exploring data insights.
-	Developing a predictive model.
-	Compare machine learning algorithms.
-	Evaluate model performance using metrics, such as accuracy, precision, recall and F1-score.

## Project Aim
The overall aim of this project is to develop a reliable and accurate predictive model for CKD diagnosis using machine learning techniques, which can assist healthcare professionals in identifying high-risk patients and providing early interventions.
